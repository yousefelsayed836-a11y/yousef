# Project Tools — Active on All Windows & Conversations

This repository includes four tools that activate automatically in every Claude Code session.

## Tools Included

### 1. Caveman Mode (Browser Extension)
Located in `extension/`. Reduces output tokens by ~65% on ChatGPT, Claude, and Gemini.
Load it in Chrome/Edge as an unpacked extension from the `extension/` folder.

### 2. Taste Skill (Frontend Design)
Located in `taste-skill/`. Anti-slop frontend design skills for landing pages, portfolios, and redesigns.

### 3. Claude-Mem (Persistent Memory)
Located in `claude-mem/`. Persistent memory system across Claude Code sessions.

### 4. Humanizer (.NET Library)
Located in `humanizer/`. .NET library for turning strings, enums, dates, times, numbers, and quantities into human-friendly text.
